# 3-Minute Demo Script

## 0:00 - 0:35

Open the marketplace and frame the problem:

"Most AI demos stop at the prompt box. SkillCapsule turns a prompt into a reusable product unit with storage proof, compute proof, and onchain publish evidence."

## 0:35 - 1:20

Open `Creator Studio`:

- choose a template
- upload a knowledge file
- create a manifest
- explain that the browser pins knowledge to `0G Storage`

## 1:20 - 2:00

Open the new capsule detail page:

- show system prompt and result schema
- click `Publish to 0G chain`
- explain the registry contract and explorer trail

## 2:00 - 2:45

Run the capsule:

- enter a task
- show result generation
- open `Proof Drawer`
- call out manifest root, registry tx, compute mode, and proof hash

## 2:45 - 3:00

Close with:

"This is a creator marketplace for verified AI work products. The capsule is portable, reproducible, and demo-ready on top of 0G."
